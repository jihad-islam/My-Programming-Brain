# My Programming Brain 🧠

Welcome to **My Programming Brain**! This repository serves as my personal knowledge base and digital garden where I note down every learning topic related to Software Engineering and Competitive Programming (CP).

## 🗂️ Contents

### Core Subjects
- **[1. C Programming](1.%20C/)**: Basic concepts, data types, loops, arrays, pointers, functions, strings, and recursion.
- **[2. C++ Programming](2.%20C++/)**: Dynamic memory allocation, OOP (Class and Object, Inheritances, Polymorphism), STL, and string classes.
- **[3. Data Structures](3.%20Data%20Structure/)**: Arrays, Linked Lists (Singly & Doubly), Stacks, Queues, Binary Trees, BSTs, Heaps, and time/space complexity analysis.
- **[4. Algorithms](4.%20Algorithm/)**: Sorting, Graph Representation, BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, DSU, MST, and various classic algorithms.
- **[5. Database (MySQL)](5.%20MySQL/)**: Queries, Joins, sub-queries, functions, relations, and database normalization.
- **[6. Python](6.%20Python/)**: Syntax, OOP, NumPy, various projects, and the "100 Days of Code" journey.

### Practice & Problem Solving
- **[Problem Solving](Problem%20Solving/)**: My solutions and approaches to various competitive programming problems (LeetCode, Math, Strings, etc.).
- **[Practice](practice/)**: Random practice scripts, experiments, and exam-related code snippets.
